# EP01 v3 镜头表

系列：《侯府嫡女：今生换你们跪》
成片：`final/ep01-v3.mp4` — 110 秒，1080×1920，56 个切点（平均 2.0 秒一刀）

## v3 相对 v2 的三处结构性改动

1. **动作有真实位移。** 每个关键节拍准备 A、B 两张姿态图。小幅动作（举杯饮下、伸手递酒、推杯、眼神抬起、冷笑）用运动补偿插值生成中间帧，配合三帧平均的运动模糊；大幅位移（倒地、睁眼重生、惊退）改用硬切，因为插值在大位移上会把人物拉成橡皮。眨眼是 4 帧硬切，不做溶接。
2. **按多机位方式剪辑。** 同一张原画按不同景别和取景点切出 2–5 个"机位"，并在节拍中途插入其他角色的反应镜头（毒酒微距、男主冷眼、倒地的女主），使相邻镜头换的是主体而不只是裁切比例。
3. **冷开局。** 开场 1.6 秒直接是女主口吐鲜血倒地，烛火压缩到 1.4 秒。

## 转场规则

只有三处用溶接，其余全部硬切：

- 羞辱 → 长廊：淡入淡出 0.5s（换场）
- 长廊 → 闭眼：淡入淡出 0.4s（意识消散）
- 闭眼 → 睁眼：白闪 0.25s（重生）
- 冷视 → 片尾卡：淡入淡出 0.4s

## 画面处理

- 原画按 1.5 倍超采样后裁切竖屏，取景点在横向留白内平移，避免直接放大糊掉
- 变焦上限 1.5，超过这个倍率脸会明显发软
- 全片 `unsharp` 轻锐化 + 颗粒，抵消放大带来的塑料感
- 烛光场景加正弦亮度扰动模拟烛火
- 冲击镜头（倒地、睁眼、推杯、惊退）加手持晃动
